# Сайты Татьяны Желиховской

Главный сайт. Карточки в «Витрине» ведут на 6 отдельных сайтов-примеров (каждый — свой репозиторий: noir-motors, portrait-gallery, breathe, synapse, velmont, dubai-night). Все кнопки «Сайт сделан Татьяной Желиховской» и «Записаться» ведут на одну ссылку.

## Как вставить свою ссылку
Ссылка уже вставлена в файл `link.js`. Если захотите поменять — замените её там, и она обновится на всех страницах.

## Как выложить на GitHub Pages
1. Создайте новый репозиторий на github.com.
2. Нажмите **Add file → Upload files** и перетащите всё содержимое этой папки (не саму папку).
3. Откройте **Settings → Pages**, в разделе Source выберите ветку `main` и папку `/ (root)`, нажмите Save.
4. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

Цены в тарифах на главной: найдите в `index.html` строки с `XX XXX ₽` и впишите свои суммы.
